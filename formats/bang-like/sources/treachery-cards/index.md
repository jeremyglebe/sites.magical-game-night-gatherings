# Treachery Card Images

This repository preserves the Treachery 2025 Identity cards, tokens, and oracle data as reference material. For the actual game procedure, read the [Treachery rules](../../variants/treachery.md).

## Card text and images

- [Download the archived oracle JSON](../treachery-cards-oracle.json): the 62 Identity records stored with this catalogue.
- [Browse the archived card images](https://github.com/jeremyglebe/magical-game-night-gatherings/tree/main/formats/bang-like/sources/treachery-cards): individual PNGs in the repository.
- [Current Treachery Oracle](https://mtgtreachery.net/rules/oracle/): current card wording and card-specific notes maintained by the format's authors.
- [Printable cards and tokens](https://mtgtreachery.net/en/#download): A4 and US Letter sheets and individual images.

The local archive is a snapshot. If using updated Identity cards, use the matching current oracle and rules from the authors.

Primary source page: [MTG Treachery](../mtg-treachery.md)

Original site: <https://mtgtreachery.net/en/>
