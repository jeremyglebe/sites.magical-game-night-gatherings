# Creature Feature

[All formats](../)

Creature Feature is the local Pegasus Loft constructed format built around creature density and a shared creature type.

## Rulesets

| Ruleset | Contents |
| --- | --- |
| [Creature Feature rules](rules.md) | Deck-size and creature-count requirements, rounding, changelings, temporary type bans, prohibited type hate, sideboarding, and event procedures. |

The rules page preserves the complete recorded local rules. It also identifies the event decisions that still need clarification, including the legal card pool and the scope of temporary type bans.

## Boxed-set use

A Creature Feature box should identify its featured types, decks, legal card pool, and whether tournament type bans apply to repeated games with fixed decks. Any exemption or replacement rule belongs on that box's page.
