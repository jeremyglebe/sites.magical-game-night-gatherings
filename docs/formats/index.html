Formats

Choose a family below, then open one of its rulesets. Each version has a separate page so that its setup, turn procedure, and victory conditions stay together.

Format family Choose this for… Rulesets in this catalogue
Archenemy One villain against a team, with an extra scheme deck. Standard, Commander, and both Supervillain Rumble versions.
Assassin Secret player-to-player targets. Hitmen, the local Pegasus Loft rules.
BANG-like hidden roles Bluffing, hidden allies, and competing victory conditions. BANG! Magic, Kingdoms, Kingdom / BANG EDH, and MTG Treachery.
Big Deck A communal library and unexpected card combinations. Pile o' Magic and Pile o' Magic Commander.
Creature Feature Constructed decks built around a shared creature type. Pegasus Loft rules and event restrictions.
Cube Drafting a reusable, curated card pool. Booster-draft Cube; design notes for different cube types.
Horde Cooperative games against an automated enemy deck. Classic Zombie Horde, Open Source options, HordeMagic.com, the archived wiki version, and Raid.
Jumpstart Combining two prepared themed packets for a quick game. Full two-packet play rules and a reusable custom-packet preparation guide.

Formats and boxed sets

A format defines how the game works. A boxed set supplies a particular collection of decks and components, and may add its own rules. Box-specific changes belong on the boxed-set page, with a link back to the exact base ruleset.

Using the rules explains page status and rules precedence. Sources collects the original references and archived notes.
