# Using the Rules

## Pick a specific version

A format's parent page is a directory, not a substitute for its rules. Follow a ruleset link to find the materials, deck requirements, setup, turn procedure, restrictions, and victory conditions for that version.

Use one version for a game. For example, Classic Horde's random choices and HordeMagic.com's best-interest choices are different rules; neither automatically carries over to the other.

## What the pages cover

Rules pages record the format-specific procedures. They assume players know normal Magic: casting spells, priority, the stack, combat, and card text. The [official Magic rules](https://magic.wizards.com/en/rules) remain the reference for those underlying systems.

When a page uses Commander, normal Commander deck construction, the command zone, commander tax, and commander damage still apply unless that page explicitly changes them. [Wizards' Commander rules](https://magic.wizards.com/en/formats/commander) describe that base format.

Normal multiplayer setup includes an opening hand of seven and a first mulligan without reducing the final hand size. Use the current London mulligan: shuffle the hand back, draw seven, and when keeping, put one card on the bottom for each mulligan after the free first mulligan. In multiplayer games, the starting player normally draws on their first turn. A specific format rule or card may change these instructions.

## Boxed-set rules

Read the box's named base ruleset first, then its additions and replacements. A box must identify:

1. The specific base version it uses.
2. Its decks and other required components.
3. Any replacement setup, turn, or victory rule, written out in full.
4. Additional rules and the exact timing of their effects.
5. Optional modules, with an explicit decision about which are active.

Unchanged rules continue to come from the named base version. A box that has not chosen its base or victory conditions is still a draft.

## Reading page status

- **Rules:** the identified version's procedures. Any source ambiguity is stated where it matters.
- **Local rules:** the owner's house format. Existing rules are preserved; unresolved interactions are listed for a future design decision.
- **Draft:** the concept does not yet define enough rules to run without making additional choices.

An open question is not a new house rule. Examples explain recorded rules; they do not silently change them. Optional rules only apply when the group chooses them before play.

## Sources and card rulings

Rules pages link to their original references and the catalogue's [source notes](../sources/). Source notes may contain historical commentary, proposals, or different versions; they are not automatically additional rules for every game.

Use current Oracle text for official cards. Custom identities and other fan-made cards use their own published text. Card rulings do not, by themselves, decide an unfinished house-format rule.
