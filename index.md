## How to use the catalogue

Start with a **format family**, then choose a **ruleset**. Versions with different setup or victory rules have their own pages. Rules pages contain the actual format procedures; parent pages help you choose between them.

A **boxed set** is a personal play kit built around a particular ruleset. Its page names that ruleset and records the box's additions, replacements, and optional rules. Drafts show the decisions that still need to be made.

Normal Magic rules apply unless a format changes them. See [Using the rules](/rules/) for shared conventions and the difference between a recorded rule and an open design question.

This is a fan-made catalogue. The boxed sets are personal play kits, not commercial products.
