# Marvel Sets and Supporting Card Pools

**Checked: October 19, 2026.** This reference collects Marvel-branded Magic printings regardless of which product they came from, followed by other sets that could support Marvel-themed game-night boxes. It is a pool of possibilities, not a shopping list or a commitment to build one box from every set.

The released Marvel search currently reaches **21 Scryfall set codes**. That includes six principal card pools, nine promotional categories, three token sets, and three memorabilia categories. It does **not** mean there have been 21 separate Marvel expansions. Shared codes such as `SLD` contain much more than Marvel, and one retail release can use several codes.

## Finding Marvel cards across products

Scryfall's working art tag is **`art:marvel-comics`**. This catches Marvel artwork on reprints as well as cards named after Marvel characters. It is more useful than searching only names or assuming every Marvel release has its own exclusive code. Art tags are community maintained, so a newly added printing can be missing a tag.

| Purpose | Search |
| --- | --- |
| Browse Marvel cards for deck ideas | [Marvel artwork, one result per card](https://scryfall.com/search?q=art%3Amarvel-comics) |
| See alternate printings and art | [Marvel artwork, every printing](https://scryfall.com/search?q=art%3Amarvel-comics+unique%3Aprints) |
| Include tokens and other extras | [Marvel artwork with extras and all printings](https://scryfall.com/search?q=art%3Amarvel-comics+unique%3Aprints+include%3Aextras) |
| Reproduce this released-only snapshot | [Marvel printings dated on or before October 19, 2026](https://scryfall.com/search?q=art%3Amarvel-comics+unique%3Aprints+include%3Aextras+date%3C%3D2026-10-19) |
| Find Marvel Secret Lair cards without unrelated drops | [Marvel artwork in SLD](https://scryfall.com/search?q=set%3Asld+art%3Amarvel-comics) |

The broad queries without a date cutoff can include previews. `unique:prints` intentionally repeats cards with different printings; omit it when choosing distinct cards for a singleton pool. `include:extras` exposes objects such as tokens and art cards that are not ordinary deck cards.

| Code | Set name | Why it belongs in the search |

| `SPE` | [Marvel's Spider-Man Eternal](https://scryfall.com/sets/spe) | Supplemental Spider-Man cards under a separate code, also September 26, 2025. Searching only SPM misses this pool. |

Wizards' [Marvel Jumpstart themes and decklists](https://magic.wizards.com/en/news/announcements/marvel-super-heroes-jumpstart-booster-themes) explicitly identify new Jumpstart cards with **MSC**. The [Marvel collecting guide](https://magic.wizards.com/en/news/feature/collecting-marvel-super-heroes) is the companion product reference.

The first [Marvel Secret Lair Superdrop](https://magic.wizards.com/en/news/announcements/secret-lair-marvel-superdrop) went on sale **November 4, 2024**, before the Spider-Man expansion. It consisted of five character drops: Black Panther, Captain America, Iron Man, Wolverine, and Storm. Those drops share SLD; they are not five separate Scryfall set codes. The date of the overall SLD category is not the release date of its Marvel cards.

To browse the main dedicated pools plus Marvel Secret Lair cards, use:

```text
(set:spm or set:spe or set:msh or set:msc or set:mar or (set:sld art:marvel-comics))
```

That is a practical deck-building search, not the complete promotional and memorabilia inventory below.

## Using this research in boxes

**Choose the game rules first, then build a thematic card pool that follows them.** Creature Feature counts actual creature types: Robot, Construct, Myr, Servo, and Thopter are not synonyms. A supporting creature that looks like a robot does not automatically meet a Robot requirement. See the [complete Creature Feature rules](../formats/creature-feature/rules.md).

A Horde can mix mechanical-looking creature types when its selected rules allow it. Check targeting, optional abilities, repeated activations, and infinite-mana interactions before adding complex cards. Any special automation procedure belongs explicitly in that box's rules. Do not assume a thematic card can run itself.

For an Age of Ultron idea, anonymous machines can be more coherent than importing another villain's distinctive army. The verified card [Ultron, Machine Overlord](https://scryfall.com/card/msc/507/ultron-machine-overlord) is a Robot Villain and gives other Robots and Constructs +2/+2. That is a specific card option, not a requirement to buy Ultron or make every Marvel card fit that box.

The project's preference is variety and usually one copy of each nonbasic card, with duplicates justified by a real play requirement. A themed box need not consume every spare card. Several smaller boxes, a singleton cube, and reusable [Jumpstart packets](../formats/jumpstart/building-packets.md) can use different parts of these pools.

## Sources and maintenance

- Set names and codes: [Scryfall set directory](https://scryfall.com/sets) and [set metadata API](https://api.scryfall.com/sets), checked October 19, 2026.
- Card names, types, token profiles, and searches: Scryfall, queried through the project's [Scryfall MCP server](https://github.com/cryppadotta/scryfall-mcp).
- Product context: Wizards' [2024 Marvel Secret Lair announcement](https://magic.wizards.com/en/news/announcements/secret-lair-marvel-superdrop), [Marvel collecting guide](https://magic.wizards.com/en/news/feature/collecting-marvel-super-heroes), and [Marvel Jumpstart themes](https://magic.wizards.com/en/news/announcements/marvel-super-heroes-jumpstart-booster-themes).

The 21-code inventory was obtained by searching `art:marvel-comics date<=2026-10-19 include:extras unique:prints`, then excluding already found set codes until no results remained. A cross-check of the dedicated SPM, SPE, MSH, MSC, and MAR pools found no released cards missing that art tag at the time. This is a dated best-effort catalogue, not a promise that future printings will be tagged immediately.

When updating it, repeat the unrestricted Marvel-art search, inspect new set codes, check individual printing dates in shared promotional/Secret Lair categories, and keep upcoming material separate from released cards. Preserve this distinction rather than treating a set category's start date as every card's release date.
