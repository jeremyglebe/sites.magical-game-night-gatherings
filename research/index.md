# Project Research

Saved references for building reusable Magic game-night boxes. These pages collect card pools, exact names, search links, and design possibilities; a research entry is not a finished deck or an adopted house rule.

| Reference | What it contains |
| --- | --- |
| [Useful Products & Tools](useful-products-and-tools.md) | Saved purchase links, exact product variants, seller fallbacks, fit notes, and the storage calculator. |
| [Card storage calculator](card-storage-calculator.md) | Interactive stack sizing, box capacity, single and double sleeves, measured compression states, and product comparisons. |
| [Custom Jumpstart storage system](jumpstart-storage.md) | Twenty-four-packet storage requirements, preferred Burger Tokens boxes and larger fallback, insert presentation, earlier product comparisons, and physical-fit measurements. |
| [Marvel sets and supporting card pools](marvel-card-pools.md) | Marvel set names and Scryfall codes, Secret Lair and promotional printings, tokens, upcoming releases, generic machines, and useful crossover settings. |
| [Everyday life and ordinary New York](everyday-life.md) | A researched catalogue of ordinary people, animals, food, objects, transport, and places, with separately identified almost matches. |

Each reference records when it was checked and how to repeat the searches. Card links point to particular printings so that the artwork and setting can be considered alongside the rules text.

For complete play procedures, use [Formats](../formats/). For an actual box's chosen rules and contents, use [Boxed Sets](../boxed-sets/). Original format articles and archived material are indexed under [Sources](../sources/).
